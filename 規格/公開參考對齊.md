## 第十輪 CAD 調整摘要（2026-08-16：電源上移 / 孔位翻面 / 以底板為基準的互鎖鏈 / PCIe 窗框）

使用者驗收：電源上面還有空間、風扇會朝上、只有頂蓋與碟架有卡槽、
底板與側板／後板缺卡榫、組裝順序應該是底板→側板→後板→碟架→前罩、
PCIe 還是很多問題、「你確定這些孔位都有放正確嗎」。

1. **`AREA_A_CLEARANCE` 50.00 → 76.20 = Table 6 required，機殼高度不變。**
   電源頭上量出 **27.50 mm 死空間**（第八～九輪 `ATX_Z0` 只由 Area A 往上推、
   沒有人問頂上還剩多少）。電源整組上移 26.20，讓出來的全部變成板上淨空。
   **第八輪那條「刻意的規範偏離」就此消除**；`PSU_CLEAR_ABOVE` 改成導出值
   （`INNER_TOP_Z − ATX_Z1` = 1.30），verify 同時驗它 ≥1.0 **和** ≤6.0。
2. **ATX 四孔繞深度軸轉 180°**（風扇朝下）。⚠️ **這是假設不是規格**：
   ATX12V v1.1 Fig.4 p23 的風扇開在**後面板**（80 mm），大面 120/140 風扇在哪一面
   規格沒有寫。verify 驗「轉回去等於 Fig.4 literal」（確認是剛體變換）並發 `WARN`。
3. **互鎖鏈改成使用者指定的順序**，唯一來源 `參數.ASSEMBLY_STEPS`；
   verify **逐步**掃描（第 i 件只看前 i−1 件）。順帶證明第八～九輪文件寫的順序
   （後牆自 +Z 落下）**做不到**——側板在位時定位舌口袋上方是實牆。
4. **全機配合面補滑配**：量出來 `distToShape` 全部 0.0000。
   一道滑槽的四個數字改成導出：舌 1.30 / 槽深 1.60 / 槽背 0.80 / 承載唇 1.10。
   頂蓋側舌的咬合量 **0.40 → 1.30**（舊算式把 `TOP_FIT_GAP` 疊了兩次）。
5. **後牆的底板槽補承載唇**（第九輪只修了側板那一半，後牆仍是 0.00 mm³）；
   新增底板側緣 bead ×4、底板後舌半球 ×2、前罩頂／底搭接 detent ×4。
6. **PCIe 窗框整圈往機殼外補強 4.0**（第九輪只補三根肋）：舌袋背後剩料
   1.10 → **5.10**；keyhole 蘑菇柱頸 4.0×5.5 → **8.0×5.5**（斷面 22 → 44 mm²）。
7. **`install_depth_mm()` 修正**：舊版拿函式跟自己的定義比（vacuous），
   且最凸的是蘑菇柱 8.00 不是壓條 5.00 → 306.00 改成 **309.00**，改由 `obb().YMin` 量。
8. **新抓到的老病灶**：前罩搭接帶裡，側板外面減薄 1.5 + 內面滑槽 1.6 = 3.1 > 牆厚 2.4
   → 三道槽在那 12 mm **全部被切穿**（第八～九輪都是）。改成那三段不減薄、
   前罩殼挖對應缺口，順手變成一組真的榫與槽。
9. **孔位全面複驗**（使用者第 5 問）：microATX Fig.7 p18 九孔、ATX12V Fig.4 p23 四孔、
   **SFF-8301 Rev1.9 Table 3-1 + Fig.3-1**（A7 自 "Connector End" 量，圖上確認）、
   PCIe CEM Fig.6-2/6-4/6-17 —— 全部逐顆對上，沒有一顆要改。

驗證：build/verify/negtest **97/97**/unittest **56**/render/組裝圖/GUI 目視複檢全過。
體積 13.70 L 不變，印料 1025 → 1032 cm³。

## 第八輪 CAD 調整摘要（2026-08-11：碟平躺上置 / 全滑槽 / 壓條外置）

使用者的 `/goal`：壓體積 <15 L、碟不用外掛架直接塞進內部、滑蓋卡槽組裝不要螺絲孔、
PCIe 壓條長在外面、電源往下挪；並給了**實測元件高**：散熱器 <50、記憶體 <40。

1. **`AREA_A_CLEARANCE` 88.90 → 50.00**（實測導出）→ 電源下移 38.9 mm。
   ⚠️ **這低於 microATX Table 6 的 required 76.20**，是刻意的規範偏離，
   規格 literal 另存為 `AREA_A_SPEC_REQUIRED/RECOMMENDED` 並由 verify 盯著不准被改。
2. **下裙整組刪**（−10 mm）。它唯一的存在理由是「機殼內部放不下螺母座」；
   螺絲全刪之後理由就沒了。但**底層那條約束換了個形式繼續成立**——
   連一道從底板往上長的定位唇都放不下，所以底板改成**自 +Y 滑進牆的低位槽**。
3. **直立 2×2 碟艙 → 平躺 4 層，疊在主板前段的正上方**。
   理由：直立碟艙之所以只吃 65.10 深，靠的是「電源撐出來、本來就空著的高度」；
   電源一往下挪，碟頂 171.4 反而比新的內頂 153.32 還高。**碟必須平躺。**
   後緣 180.34 = Fig.7 的 Area A/C 界線（碟的 x 帶跨過 `AREA_A_STEP_X`）。
4. **碟改用底面孔**（SFF-8301 A7/A6/A13，圖上量到基準＝自**接頭端**）。
   托盤厚 3.0 由 p7「Fastener penetration 2.39–3.56」反推。
5. **機殼件之間一顆螺絲都沒有**：13 顆 M3 + 13 顆銅母全刪，改滑槽互鎖 + 半球 detent。
   角落不能用燕尾（大端 6–8 > 牆厚 2.4）；detent 半徑受舌厚限制（`2R ≤ 舌厚 + 凸出`）。
6. **PCIe 壓條移到機殼外面**：後牆外表面的 T 軌 + 自右外側水平滑入。
   抬升帶因此要打成**連續橫縫並通到機殼右緣**，否則壓舌撞開孔間 1.42 的肋、抽不出來。
   （★ 第九輪推翻：那條橫縫把三根肋切成懸臂，見下。）
7. 兩片頂蓋 → **單片滑入**（接縫是碟艙分段的產物，碟艙沒了它也沒理由）。
8. **A1 床 256 成為分件的正式理由**：`CASE_D = 301.00 > 256` →
   底板／側板／頂蓋只做到 `BAY_SPLIT_Y`，前方 53.76 是獨立的 `Front_Shroud`。

**結果：16.20 → 13.22 L（−18.4%）、252.7×312.3×205.2 → 252.68×301.00×173.82、
印料 1045.2 → 1004.1 cm³、零件 10 → 11、機殼五金 26 件 → 0。**

## 第七輪 CAD 調整摘要（2026-08-10：電源上置 / 單一內腔 / 碟艙打通）

1. **九孔與板緣改用 Fig.7 p18 的向量座標**：F 的 Y 由 0 → 22.86、中列 132.08 → 154.94、
   前列 204.47 → 227.33、板緣 −22.86…220.98 → **−10.16…233.68**。
   舊值把 `.900[22.86]` 讀成「後緣→B 列」；真板前緣其實在 233.68，會撞碟艙 12.7 mm。
2. **甲板（`DECK_Z=92.4`）整片刪除**，托盤併進底板；連帶刪 6 個穿艙孔、2 道走線廊、
   前檻、榫系統。**電源移到 I/O 擋板正上方**（`ATX_Z0 = AREA_A_TOP_Z + 肩`）。
3. **碟艙後壁刪除** → 三面環繞、後面直通主板腔；失去後壁的左右牆由頂橫樑 + 搭接片繫住。
4. **外形拉平成單一長方體**（階梯取消），六隻圓腳改**整圈下裙**——
   那也是主板躺下之後唯一放得下螺母座的地方。
5. 側板／頂蓋／地板的通風孔全刪，只留前柵（氣流只有一條路）。
6. 頂蓋改**嵌入式**（下垂唇會插進電源正上方），兩片改**半搭接且碟艙段在上**
   （否則拆一顆硬碟要先拆兩片蓋）。
7. PCIe 壓條凸座 2 → 1 顆（另一顆會長在電源本體裡），位置與壓條左端都由
   「電源落入時的橫移量」導出。

**結果：18.10 → 16.20 L、高度 241.8 → 205.2、印料 1294.3 → 1045.2 cm³、零件 11 → 10。**

## 第九輪 CAD 調整摘要（2026-08-11：使用者驗收 —— 承載／走線／貼合／結構）

使用者對第八輪的成品提出四點，**四點全部屬實**；量的過程中又抓到兩點。

1. **碟架最底層的導軌槽下方沒有承載料**（探針 0.00 mm³ vs 對照層 54.00）。

2. **碟的接頭端面被右立板整片擋住**（四層各 15.8–18.0 cm³）——**SATA 插不上**。

   **SATA 接頭沿端面的確切位置在 SFF-8323，`參考/` 沒有那份規格 → 不猜位置，整面讓開。**
3. **碟架置中**（使用者要求開孔左右對稱）：碟架寬 189.00，內腔 247.88，左右各 29.44；
   前罩開口距機殼左右外表面各 **33.44**。
