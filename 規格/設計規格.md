全 3D 列印 microATX NAS 機殼。唯一真實來源是 `腳本/參數.py`，本文是它的投影。
所有規格數字都指得到頁碼；指不到的一律標成估值。

> ## ✅ 板上淨空已達 microATX required（第十輪）
> `Area A` 淨空 = **76.20** = `max(實測散熱器 50.0, Table 6 required 76.20)`。
> 第八～九輪取 50.00（低於 required）的偏離**已消除，而且機殼高度一點都沒有變**：
> 電源本來頭上有 27.50 mm 死空間，把它頂到內頂，讓出來的 26.20 mm 全部變成板上淨空。
> **仍 < recommended 88.90**（要達到得再 +12.70 mm 高度，沒有換）。
> 所以可以寫「板上淨空達 required」，**不可以**寫「完全相容 microATX」。
>
> ⚠️ **PSU 大面風扇的朝向是假設不是規格**：ATX12V v1.1 Fig.4 p23 畫的是後面板

## 1. 主板固定：階梯圓柱 + 印製壓帽（使用者指定）

### 1.1 幾何（每孔一組，共九組）

| 段 | 尺寸 | 依據 |
|---|---|---|
| 粗肩 | Ø8.0 × 6.35（自底板頂面） | 6.35 = microATX §2.4.2 板底淨空；Ø8 < 10.16 keepout |
| 細軸 | Ø3.50（牙頂徑），芯徑 Ø2.30 | 主板孔 Ø3.96 → 單邊 0.23 滑配（PETG 建議 0.2–0.3） |
| 外螺紋 | 梯形，牙距 2.0、牙深 0.60、底寬 0.5p、頂寬 0.25p | 見 1.2 |
| 細軸長 | 7.57 = 板厚 1.57 + 壓帽 5.0 + 1.0 | **導出，不寫死** |
| 壓帽 | Ø9.6 × 5.0，12 道指握溝，內牙間隙 0.20/邊 | Ø9.6 < 10.16 keepout；旋合 2.5 圈 |

**真旋合徑向量 = 牙深 − 螺帽間隙 = 0.60 − 0.20 = 0.40。**（牙深不等於旋合量。）

### 1.2 三關，缺一關就是裝飾

| 關 | 門檻 | 本版 | 舊旋蓋 |
|---|---|---|---|
| ① 最小可印特徵 | 徑向 ≥0.5 | **0.60** ✓ | 0.40 ✗ |
| ② 不破 keepout | < Ø10.16 | **Ø9.6** ✓ | Ø12 ✗ |
| ③ **牙必須是螺旋** | 相位轉 180° 必須撞 | **0.00 / 6.19 mm³** ✓ | 3.5 / 3.5 ✗（軸對稱） |

第三關最致命也最久沒被發現：軸對稱的疊圓盤怎麼轉都不會撞，看起來像螺紋、轉不進去。
`_run_negtest.py` 每輪重跑一次，證明這條檢查不是空的。

### 1.3 建模注意（踩過的坑）

- **不要用 `makeHelix + MakePipeShell` 掃**：參考標架累積扭轉，三圈漂 0.35 mm
  （比 0.20 的間隙還大），外牙 r=1.15／內牙 r=0.95 漂移量還不同 → 任何相位都咬死。
  用**解析擺位 + `makeLoft(ruled=True)`**（`build_case.thread_rib`），牙心零漂移。
- **細軸最後才 `fuse`，而且不 `removeSplitter()`**：`removeSplitter` 對螺紋的 loft 面
  會把 `isValid()` 弄成 False。
- 量尺寸一律 `optimalBoundingBox(True)`：`Shape.BoundBox` 對 spline 會虛胖一倍。
- STL 匯出弦差取 **0.05**（0.25 會把 0.6 的牙磨平）。

### 1.4 列印

底板連同九根柱一起平印（柱朝上，免支撐）。壓帽 **印 9 顆**（STL 是單顆）。
**只能手緊，不要上工具。**

## 3. 後牆 / I/O / PCIe / 電源開窗

### 3.0 機殼寬度是被 I/O 開孔逼出來的

I/O 開孔遠緣 `IO_X0 = −211.99` 比板左緣 `−209.55` **再外 2.44 mm**（microATX Fig.4 必然值），
外側還要留 2.54 keepout + 可印全厚邊：

```python
CASE_LEFT = min(BOARD_LEFT - MARGIN - WALL, IO_X0 - IO_EDGE)   # IO_EDGE = 3.5
→ CASE_W = 252.68，A1 床邊剩 3.32 mm
```

不要為了「湊個好看的 250」把左壁改回貼板緣——那會讓後牆左緣只剩 0.46 mm。

### 3.2 PCIe（全部出自 `參考/PCI_Express_CEM_r2.0.pdf`）

| 值 | 來源 | 用途 |
|---|---|---|
| 18.42 / 0.86 | Fig.6-4 p95 | 擋板寬 / 料厚 20GA |
| **112.75** | Fig.6-4 | **本體**（頂緣→底肩）← 開孔對的是這個，不是全長 120.02 |
| 7.27 / 14.30 | Fig.6-4 | 底舌長 / 寬 |
| **114.55** | Fig.6-17 p110 DIM A | 板面 → 標準高卡頂 |
| 4.56 / 2.92 | Fig.6-4 側視 | 擋板頂高出卡頂 / 折耳帶 |
| **11.43** | Fig.6-4 **俯視** | 折耳向內伸長（前視那排 21,59 是凸緣「寬」，不是伸長） |
| 7.90 / 111.15 | Fig.6-17 / p94 | 連接器頂 / 標準高卡固定高 |

**指入深度 = 7.90 − (114.55 − 111.15) = 4.50**：卡要離開連接器必須整片抬這麼多。
開孔頂因此是 `PCIE_Z1 + PCIE_LIFT(6.0)`，不是 `+0.4`。

**固定件必須可拆**：耳下方可用高度 = 4.56 − 4.50 = **0.06 mm**。
`PCIeBar` 是一片掛在後牆**外面**兩顆蘑菇柱上的板（**沒有任何螺絲**）：
往 +Y 壓上去（四個壓舌各自進自己的開孔）、再往下落 `PCIE_BAR_DROP = 3.5`，
頭就被壓條窄槽兩側各 4.0 mm 的料扣住（keyhole）。拆：抬 3.5、往 −Y 拔。

**第十輪的兩件事**（使用者：PCIe 那邊還是很多問題）：
① 補強從「只有三根肋」擴大成**整圈窗框**——底檻挖完舌袋只剩 1.10 的那塊
   現在是 5.10，左右柱與底檻一起變 6.40。
② 蘑菇柱頸 4.0×5.5 → **8.0×5.5**（斷面 22 → 44 mm²）。整條壓條連同四片卡的
   防上抬就掛在這兩根上，它們就是使用者說的「只靠一點點地方連接」。

**已廢除且不得復活**：外凸 3 mm 連續耳座、外凸底卡榫、內側 7 mm 鎖固軌、
四顆穿牆固定螺絲、外側面座凹槽、長在頂蓋上的壓條、沿 X 滑入的 T 軌與連續橫縫、
以及「左端一顆 M3 鎖後牆凸座」（第七輪的做法，第八輪起壓條完全無螺絲）。

## 4. ATX 電源（上置、頂到內頂）

### 4.1 位置與姿態

| 項 | 值 | 依據 |
|---|---|---|
| 本體 | 150 × 86 × 140（艙深預留 160） | ATX12V PS/2 |
| 姿態 | **風扇朝下**（四孔繞深度軸翻 180°） | ⚠️ **假設不是規格**，見 §4.2 |
| X | **−210.89 … −60.89** | `TOP_LID_INNER_X + PSU_FIT_GAP`（讓開頂蓋下垂側舌） |
| Y | −10.66 … 149.34（後面貼後牆內面＝安裝面） | ATX12V Fig.4 |
| Z | **89.52 … 175.52** | `AREA_A_TOP_Z + PSU_LEDGE_T`（導出）；頭上剩 1.30 |

**投影必須整片落在 Area A**（B 區只有 15.24、C 區 38.10，放不下 86 高的電源）。
含 160 長機身時前緣 149.34 < Area A 界線 154.94 —— **只剩 5.6 mm**，
所以建議非模組、深度 ≤140。

**X 為什麼不再貼左內牆**：電源升到內頂之後，它的頂面（175.52）落進**頂蓋側舌**的
Z 帶（173.82–176.82）。舊的 `ATX_X0 = CASE_LEFT + WALL` 會讓電源左緣直接吃進
那條舌與它的接料。讓開 2.20 mm 就解決，右邊還有 96 mm 空著。

### 4.2 後牆鎖點（ATX12V Design Guide v1.1 **p23 Figure 4**）

規格 literal（原點＝後面板左下角，從機殼後方外側看）：
**(6,80) (144,80) (6,16) (120,6)**。
圖上量到的四條標註：`6.0 (2X)`（左右緣→孔列）、`138.0`（同列兩孔）、
`16.0 + 64.0`（左下→左上）、`6.0 + 74.0`（右下→右上）、`114.0`（左孔列→右下孔）。
**非對稱**：右下孔被 AC 插座讓開內移到 120，左下孔抬到 16。

> ⚠️ **本專案實際使用的是這四顆繞深度軸轉 180° 之後的位置**
> `(6,6) (144,6) (144,70) (30,80)`，也就是**風扇朝下（朝主機板）**。
> 理由是使用者指定，**不是規格導出**：ATX12V v1.1 Fig.4 的風扇開在**後面板**上
> （80 mm），進氣在前面板、選配在兩側——大面 120/140 風扇在哪一面這份規格沒有寫。
> verify 驗的是「把實際孔位轉回去要等於 Fig.4 literal」（確認它是剛體變換），
> 並發 `WARN`。要翻回來：`PSU_FAN_DOWN = False`。

`PSU_WIN_*` 由這四顆導出（每顆孔緣留 ≥2 mm 料），不是手寫的 inset。

### 4.3 承重

四顆 #6-32 是固定件；重量與潛變由兩條肩承擔：
**後牆前伸凸緣（12 深 × PSU 寬）+ 左側板內伸長肩（12 寬 × 140 長）**。
肩的頂面＝電源底面、底面＝Area A 淨空頂——再厚一點就是伸進規格淨空。
> 20 N 的重量、CoM 距後牆約 70 mm。PETG 常溫潛變**沒算過**（見 CONTEXT 未做）。

### 4.4 裝入路徑

自上方落入，但**必須先往 +Y 移 7 mm** 讓開後牆頂鉤唇（前伸 6.0），
落到承托肩上再往 −Y 推到位。verify 把這兩步都掃出來驗
（不讓位的話電源掃上去撞鉤唇 450 mm³——最終位置合法、路被擋住）。

### 6.2 為什麼是「底板插進牆」而不是「牆插進底板」

```text
內寬 247.88 − 板寬 243.84 = 左 3.54 / 右 0.50
內深 244.84 − 板深 243.84 = 1.00
板底 6.35（§2.4.2）把 z∈[2.4, 8.75] 也封死
→ 任何從底板往上長的定位唇，右側和後側都會直接戳進主板
```

第七輪的解是下裙（座長在地板以下）。第八輪螺絲整組拿掉之後，**同一條約束換了個
形式繼續成立**：底板三面各伸出舌，插進牆內面的槽，**自 +Y 水平滑入**。方向是反過來的。

> **第九輪修了側板那一半、第十輪才把後牆那一半也修掉。** 第八輪的槽開穿到牆底
> （z 從 −0.1 起），**槽的下方一點料都沒有**——那是 L 形搭邊不是槽。
> 使用者第九輪問「主機板託盤跟左右板之間，真的有滑蓋設計嗎」，答案當時是：不是。
> 第九輪只補了側板；**後牆那一道原封不動**（探針 0.00 mm³），所以使用者第十輪
> 又問了一次。同一個病灶修一半、另一半留著，一定會被再問一次。

### 6.3 一道滑槽的四個數字（牆厚 2.4 全部要塞進去）

```text
舌伸出 FLOOR_LIP = TOP_LIP = 1.30       ← = WALL − GROOVE_BACK_MIN − SLIDE_FIT
槽深   = 舌 + SLIDE_FIT = 1.60
槽背後 = 2.4 − 1.60 = 0.80 = GROOVE_BACK_MIN（FDM 最小可印壁厚）
底板舌厚 1.00、承載唇 = 2.4 − 1.0 − 0.3 = 1.10
```

**第十輪之前，這四個數字只有「舌伸出」是對的**：量出來
`distToShape(底板, 側板/後牆/頂蓋)` **全部 0.0000** —— 底板本體寬度剛好等於內腔
247.88、舌尖與槽底共面、舌底與承載唇共面。零間隙不是精密，是裝不上（硬規則 19）。

### 6.4 接合介面（**機殼件之間一顆螺絲都沒有**）

| 介面 | 方式 | 保持力 |
|---|---|---|
| 底板 ↔ 左右側板 | 底板兩側**上半舌**（1.0 厚 @ z∈[1.4, 2.4]）插進側板低位槽（深 1.60，下留 1.10 承載唇）；**側板自 +Y 往 −Y 滑上底板** | 底板側緣**縱向 bead**（R 0.9／凸 0.6，軸沿 Z）×2／側，位於底板後段 → 只有最後 30 mm 過盈 |
| 底板 ↔ 後牆 | 底板後緣同樣的上半舌插進後牆低位槽；**後牆自 −Y 往 +Y 推入** | 舌上表面 2 顆半球（R 0.80／凸 0.60），後牆槽頂有對應凹坑 |
| 左右側板 ↔ 後牆 | 後牆兩端前伸的薄定位舌（1.2，槽深 1.5） | **不對稱單向楔 ×3／側**（第十一輪）：楔長在側板口袋底，斜坡 1.5（21.8°）朝 −Y、平台 0.8、**直角面 0.6 × 5.0 朝 +Y**；後牆舌上自舌根往前開缺口。**推得進去、拉不出來** |
| 碟架 ↔ 左右側板 | 四條橫樑的側舌（1.2）插進側板 z∈[165.82, 171.82] 的槽，自 +Y 滑入，**推到盲端 `RACK_STOP_Y = 182.04` 止住** | 盲端擋 −Y（第十輪槽開到 179.34 → 浮 3.00）、前罩擋 +Y、頂蓋壓住頂板 |
| 頂蓋 ↔ 左右側板 | 兩側下伸舌插進 z∈[174.12, 177.42] 的槽，**咬合 1.30**（第九輪只有 0.40），自 +Y 滑入 | 槽上方仍有 2.70 牆料 → 抬不起來 |
| 頂蓋 ↔ 後牆 | 後端切掉上半，鑽進後牆頂鉤唇（1.5 厚、前伸 6.0）下方 | 半搭接互鎖 |
| 前罩 ↔ 主板段 | **四面半搭接** + **三段整厚料咬進搭接殼的缺口**（見下） | 左右各 3 顆 + 頂底各 2 顆 detent，共 **10 顆** |
| 碟托盤 ↔ 碟架 | 兩側導軌舌（4.0 × 2.0）滑進立板內面的槽 | 前擋板即面板，靠手抽 |
| PCIe 壓條 ↔ 後牆 | 後牆**外表面**兩顆蘑菇柱（頸 **8.0** 寬 / 頭 **16.0** 寬 × 高 3.0）；壓條往 +Y 壓上、再落 3.5（keyhole） | 柱翼上 4 顆 detent |

**為什麼角落不用燕尾**：燕尾大端要 6–8 mm，牆厚只有 2.4——兩片 2.4 的板咬不住。
**detent 半徑受載體厚度限制**：`2R ≤ 載體厚 + 凸出量`。
**公母要放在有料的那一邊**（第十輪）：球長在 2.4 的牆上、坑挖在 1.2 的舌上。
反過來（第九輪的做法）算下去是「槽深 1.5 + 凸出 0.6 + 坑加大 0.15 = 2.25，
牆只剩 0.15」——**牆厚 2.4 根本排不下**。

**半球是摩擦力，不是保持力**（第十一輪）：受拉時球會沿球面自己爬出來（cam-out）。
量出來後牆往 −Y 走 **12 mm 都沒有任何幾何擋住** —— 而後牆正是 AC 線、I/O 線、
PCIe 卡拔插時受 −Y 力最多的那一面。要「拉不出來」就得有一個**法線平行拉出方向的
直角面**；純滑動接合的公母進出走同一道邊，所以不對稱只能做在**公件**上。
母缺口要**自舌根往前開**（直角面推的是缺口前緣，後面必須是整片料）。
**前罩 10 顆與底板後舌 2 顆刻意維持半球** ＝ 拆卸路徑；全做成單向就永遠拆不下來。
**側板必須外表面朝下印**：楔凸出的方向就是列印 Z。

**前罩的第三個咬合**（第十輪，順手從一個缺陷變出來的）：
側板的搭接減薄帶在**三道內面滑槽的正後方不減薄**（1.6 槽 + 1.5 減薄 = 3.1 > 2.4，
那一段本來是被切穿的），前罩的搭接殼挖對應缺口 → 那三段整厚料就是榫、缺口就是槽，
前罩在 Z 上被扣死，不只是靠 detent 摩擦。

**互鎖鏈的收尾**：頂蓋兩側舌上方仍是牆料（抬不起來）→ 後端鑽進鉤唇（前後也鎖住）
→ 側板連帶抽不上去 → 前罩擋住頂蓋往 +Y 滑出。
