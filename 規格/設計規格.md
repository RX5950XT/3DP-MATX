## 1. 主板固定：Ø8 支撐肩盲內牙 + 專用印製螺絲

### 1.1 幾何（每孔一組，共九組）

| 段 | 尺寸 | 依據 |
|---|---|---|
| 支撐肩 | Ø8.0 × 6.35（自 Chassis 地板頂面） | 6.35 = microATX §2.4.2 板底淨空；Ø8 < Ø10.16 keepout |
| 盲內牙 | major Ø3.50、minor Ø2.30、牙深 0.60 | 保留於 Ø8 肩內，不再有細軸穿出 PCB |
| 牙形 | 梯形；pitch 2.50、root 0.50p、crest 0.25p | 5.00 mm 正好 2 圈，內牙牙頂可由 0.4 nozzle 成形 |
| 旋合 | 軸向 5.00；單邊間隙 0.20 → 徑向真旋合 0.40 | `MB_THREAD_ENGAGEMENT`／`MB_THREAD_GAP` |
| 盲孔 | 深 5.20（旋合 5.00 + 端隙 0.20） | 孔底至地板頂仍有 **1.15 mm** 實料 |
| `MB_Screw` | 牙長 6.57（PCB 1.57 + 旋合 5.00）；8 mm AF × 2.4 高六角頭 + 頭頂 5.6 × 1.8 × 深 1.5 直邊十字槽 | 頭外接徑 9.24 < Ø10.16 keepout；槽外料 1.20、槽頂料 0.90 |

### 1.2 三關與非空驗證

1. **可印**：牙深 0.60、女性牙頂約 0.85，功能特徵不低於 0.5 mm。
2. **不破 keepout**：肩 Ø8、頭外接徑 9.24 均小於 Ø10.16。
3. **真螺旋**：工作相位可旋入；螺絲相位轉 180° 必須與內牙碰撞。軸對稱疊圓盤假牙
   旋轉前後都不撞，會被 `_run_negtest.py` 拒絕。
4. **盲底存在**：verify／negtest 直接探孔底 1.15 mm 實料；把孔打穿就必須紅。
5. **PCB 上方無固定柱**：在 PCB 上方中心探點不得有 Chassis 料。

### 1.3 建模與列印

- 內外牙都用解析相位 + `makeLoft(ruled=True)`；不要用會累積標架扭轉的
  `makeHelix + MakePipeShell`。
- 含螺紋 shape 不做 `removeSplitter()`；尺寸用 `optimalBoundingBox(True)`，STL 弦差 0.05。
- `MB_Screw` 印 11 顆（主板 9 + PCIeBar 2），0.12 mm、100% infill、無支撐，
  六角頭平面貼床 —— 十字槽開在**那一面**，所以是第一層的孔，不需支撐。
- 從 PCB 上方逐顆**手緊**；不要使用電動工具。扭力、強度與拆裝壽命仍待實印。

## 3. 後牆 / I/O / PCIe / 電源開窗

### 3.0 機殼寬度是被 I/O 開孔逼出來的

I/O 開孔遠緣 `IO_X0 = −211.99` 比板左緣 `−209.55` **再外 2.44 mm**（microATX Fig.4 必然值），
外側還要留 2.54 keepout + 可印全厚邊：

```python
CASE_LEFT = min(BOARD_LEFT - MARGIN - WALL, IO_X0 - IO_EDGE)   # IO_EDGE = 3.5
→ CASE_W = 252.68，A1 床邊剩 3.32 mm
```

不要為了「湊個好看的 250」把左壁改回貼板緣——那會讓後牆左緣只剩 0.46 mm。

### 3.2 PCIe（全部出自 `參考/PCI_Express_CEM_r2.0.pdf`）

| 值 | 來源 | 用途 |
|---|---|---|
| 18.42 / 0.86 | Fig.6-4 p95 | 擋板寬 / 料厚 20GA |
| **112.75** | Fig.6-4 | **本體**（頂緣→底肩）← 開孔對的是這個，不是全長 120.02 |
| 7.27 / 14.30 | Fig.6-4 | 底舌長 / 寬 |
| **114.55** | Fig.6-17 p110 DIM A | 板面 → 標準高卡頂 |
| 4.56 / 2.92 | Fig.6-4 側視 | 擋板頂高出卡頂 / 折耳帶 |
| **11.43** | Fig.6-4 **俯視** | 折耳向內伸長（前視那排 21,59 是凸緣「寬」，不是伸長） |
| 7.90 / 111.15 | Fig.6-17 / p94 | 連接器頂 / 標準高卡固定高 |

**指入深度 = 7.90 − (114.55 − 111.15) = 4.50**：卡要離開連接器必須整片抬這麼多。
全寬開孔頂因此是 `PCIE_OPEN_Z1 = PCIE_Z1 + PCIE_LIFT(6.0) = 135.43`，不是 `+0.4`。

**開孔頂是 45° 尖頂**（第十三輪）：自 135.43 收斂到 `PCIE_APEX_Z = 144.88`（尖高
= 半寬 9.45）。理由不是造型，是**列印**——矩形頂是 18.9 mm 寬的水平懸空，切片器
會在四個 118 mm 深的槽裡各長一根支撐塔，塔與 1.42 mm 的肋咬死，使用者實印時
拆支撐把三根肋一起扯斷。45° 讓切片器判定不需支撐 → 根本不用拆。副作用是三根肋的
上端由三角形連成桁架，比原本的矩形繫樑更剛。繫樑上移到 z 144.88…151.38
（`PCIE_TIE_H` 6.0 → **6.5**，多的 0.5 是給盲牙孔底留 1.30 實料）。

**固定件必須可拆**：耳下方可用高度 = 4.56 − 4.50 = **0.06 mm**。
`PCIeBar` 位於後牆外側，5 mm 本體有四個獨立壓舌、**2 個 Ø3.96 通孔**與
**Ø9.84 × 深 3.43 的沉頭凹**；Chassis 對應繫樑上兩個 **Ø3.50 major、深 5.20 的
印製盲內牙**（軸沿 −Y，孔心 z = 148.13，盲端到後牆內面仍留 1.20）。
從外側鎖入 **2 顆印製 `MB_Screw`**：沉頭凹底剩 1.57 = `PCB_T`，夾持厚與主板相同，
所以是同一顆螺絲、不新增第九種 STL；螺絲頭沉進凹裡不凸出壓條。
拆卡必須先鬆兩螺絲，沿 −Y 抽走 Bar，四槽才可垂直抬升至少 4.50 mm。

★ 為什麼盲牙軸還是 −Y（水平孔，FDM 上牙谷會下垂）而不是列印品質更好的 +Z：
垂直盲牙的螺絲頭必須落在後牆外表面之外，Ø9.24 的頭要 4.62 mm 的 Y 半徑，而繫樑
只有 `WALL + PCIE_RIB_D = 6.40` 厚 —— 補到放得下就得往 −Y 再凸 3 mm 以上，
Chassis 的 A1 餘量只剩 **0.81 mm/邊**（實測凸 2.5 就是 255.4 裸深，加支撐直接超床）。
機殼尺寸不為一個鎖點被撐爆；保持力改靠「孔裡真的有牙」，而不是 #6-32 自攻擠塑膠。

#### 6.3.1 舊滑槽的四個數字（歷史）

```text
槽深   = 舌 + SLIDE_FIT = 1.60
```

**detent 半徑受載體厚度限制**：`2R ≤ 載體厚 + 凸出量`。
**公母要放在有料的那一邊**（第十輪）：球長在 2.4 的牆上、坑挖在 1.2 的舌上。
反過來（第九輪的做法）算下去是「槽深 1.5 + 凸出 0.6 + 坑加大 0.15 = 2.25，
牆只剩 0.15」——**牆厚 2.4 根本排不下**。

**半球是摩擦力，不是保持力**（第十一輪）：受拉時球會沿球面自己爬出來（cam-out）。
量出來後牆往 −Y 走 **12 mm 都沒有任何幾何擋住** —— 而後牆正是 AC 線、I/O 線、
PCIe 卡拔插時受 −Y 力最多的那一面。要「拉不出來」就得有一個**法線平行拉出方向的
直角面**；純滑動接合的公母進出走同一道邊，所以不對稱只能做在**公件**上。
母缺口要**自舌根往前開**（直角面推的是缺口前緣，後面必須是整片料）。
**前罩 10 顆與底板後舌 2 顆刻意維持半球** ＝ 拆卸路徑；全做成單向就永遠拆不下來。
**側板必須外表面朝下印**：楔凸出的方向就是列印 Z。

**前罩的第三個咬合**（第十輪，順手從一個缺陷變出來的）：
側板的搭接減薄帶在**三道內面滑槽的正後方不減薄**（1.6 槽 + 1.5 減薄 = 3.1 > 2.4，
那一段本來是被切穿的），前罩的搭接殼挖對應缺口 → 那三段整厚料就是榫、缺口就是槽，
前罩在 Z 上被扣死，不只是靠 detent 摩擦。

**互鎖鏈的收尾**：頂蓋兩側舌上方仍是牆料（抬不起來）→ 後端鑽進鉤唇（前後也鎖住）
→ 側板連帶抽不上去 → 前罩擋住頂蓋往 +Y 滑出。

```text
SATA：碟的 +X 端 → 碟架內的接頭區（30 寬 × 101.6 深 × 122 高，托盤當底）
      → 碟架右側空帶（29.44）→ 往下到板右緣（Area B）
```

**沒有穿艙孔、沒有隔板**。verify 有 9 個探點證明「出線口到主板上方」是空的、

——**接頭區必須對全部印件淨空**。第八輪沒有這塊虛擬件，所以右立板貼死接頭面
八輪都沒被抓到。
