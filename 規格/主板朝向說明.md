# 主板朝向說明

## 定案（2026-08-07 修正）

**機殼 case 座標對 Intel Fig.3 做 X 鏡像：`case_X = −intel_X`。**  
這樣平放裝真板時，從機殼**後方外側**看：**I/O 在左、PCIe 在右**——與 ASUS 等商品照／實機一致。

先前版本把 Fig.3 印刷左右直接當 case 左右，導致 PCIe／擋板在錯邊，**主板裝不進去**。已鏡像修正並 rebuild／verify 全綠。

## 座標系

| 軸 | 意義 |
|----|------|
| Datum B | (0, 0) 孔 B |
| +Y | 板前 → 硬碟艙 |
| −Y | 板後 → I/O 後牆 |
| +Z | 上 |
| case X | **−intel X**（孔距不變，左右翻轉） |

## 後牆（從外側看，gaze = +Y，畫面右 = +X）

| 項目 | case X |
|------|--------|
| I/O 開孔 | **−211.99 … −53.24**（畫面左） |
| PCIe×4 中心 | **+24.13, +3.81, −16.51, −36.83**（偏畫面右；第一槽在擴充側緣內 10.16） |
| 九孔 | B=0；F=**−203.20**；R=**+20.32** 等（intel 取負） |

## 與真板對齊方式

1. 商品照慣例：I/O 在圖左、PCIe 在圖下  
2. 把 I/O 邊對準機殼後牆  
3. 此時 PCIe 擋板應對準後牆**右側**開孔——本 CAD 已如此  

見 `規格/真板對齊證明.png`（旋轉示意；case 已依此鏡像）。

## 不要再改回的錯法

- 不要用「Fig.3 圖左 = case 左」直接建後牆（那是鏡像錯）
- 碟艙仍在 **+Y 前緣**，不是左右對調問題
- **不要把 `.900 [22.86]` 當成「板後緣 → B 列」**：它是「B 列 → F 那一顆」。
  照那樣讀會讓七顆孔差 22.86、板前緣差 12.7 mm（真板會撞碟艙）。
