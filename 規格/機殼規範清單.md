# mATX 機殼設計規範清單（研究摘要）

> 來源：microATX 1.2、ATX 2.1、ATX12V、PCIe CEM、SFF-8301 + 本專案對照  
> **合規核心是「介面幾何」**，不是「必須金屬盤／金屬銅柱」。

## 1. 必讀規範與關鍵數字

| 規範 | 機殼必須對齊什麼 |
|------|------------------|
| **microATX 1.2** | 板 ≤243.84²；九孔 B,C,F,H,J,L,M,R,S；Datum B=0,0；孔 Ø3.96；最多 4 擴充槽；槽距 **20.32**；第一槽中心≈左緣 **+10.16**。**九孔 Y 要照 Fig.7 p18 的向量座標**（F 在 22.86、中列 154.94、前列 227.33、板緣 −10.16…233.68），不要把 `.900` 當成「後緣→B 列」 |
| **I/O（ATX 共用）** | 開孔 **158.75×44.45**；底緣＝板頂下 **3.81**；keepout **2.54** 內外側無突片；夾壁 **0.94–1.32**；角 R≤**0.99**；B→近緣 **53.24** |
| **板底淨空** | PCB 底全域 ≥**6.35**；**僅**孔心 10.16 方形 keepout 可接觸 standoff；其餘機殼結構不得碰板底 |
| **Area A/B/C**（§2.4.1 Table 6 + Fig.7） | 板上機殼淨空：**A 76.2 required／88.9 recommended**、**B 15.24**（擴充槽區）、**C 38.10**。界線座標見 `規格/主板孔位.md`。**本專案把電源放在主板正上方，靠的就是 Area A**——第十輪起取 **76.20 = required**（電源上移到內頂換來的，機殼高度不變）；仍 < recommended 88.90 |
| **ATX12V PSU** | 150×86×140；後牆 4×#6-32 **非對稱** (6,80)(144,80)(6,16)(120,6)（p23 Fig.4）；孔距 138×74；**機殼定位特徵不得侵入這個直方體**；風扇朝下＝標準姿態（第七輪上置後，風扇吸的是機殼內部的熱空氣，不再需要地板柵） |
| **PCIe CEM r2.0** | 擋板全長 **120.02** = 本體 **112.75** + 底舌 **7.27**×14.30；寬 18.42、厚 0.86；板面→卡頂 **114.55**（Fig.6-17 DIM A）；擋板頂緣再高 4.56。**機殼開孔對本體，不是全長**；**開孔頂還要再高「指入深度」4.50**（Fig.6-17 連接器 7.90 − 卡底 3.40；卡高 111.15 見 p94），否則卡插不進去 |
| **SFF-8301 3.5"** | 101.60×≤147；高 17.8/26.1/42。**姿態決定用哪組孔**：直立用側孔（A10 = 6.35 離底面、A8 = 28.50 離接頭端、A9 = 101.60）；**平躺用底孔（本專案）**：A7 = 41.28 自**接頭端**→第一排、A6 = 44.45 →第二排、A13 = 76.20 →第三排、A5 = 3.18 側緣→孔心、A4 = 95.25。§3.1：只有 A7 那對是規格保證的。**貫入 2.39–3.56（p7）決定托盤厚度** |

## 2. 本專案分件（11 件）— 必須分開印

| 件 | 角色 | 接合 |
|----|------|------|
| 底板_主板托盤 | 實心地板 + 九根階梯柱（Ø8 粗肩 6.35 → Ø3.50 細軸 + 梯形外螺紋）+ **三面伸出 1.2 的舌**。**不開任何孔** | **自 +Y 滑進三面牆的低位槽** |
| 後牆_IO與PCIe | I/O（下）+ 4×PCIe（右，**整圈窗框往機殼外補強 4.0**）+ **PSU 開窗（上）+ ATX 四孔 + PSU 承托凸緣** + **外表面兩顆 keyhole 蘑菇柱** + 頂鉤唇 + 兩端定位舌（上開單向楔的缺口） | **自 −Y 推入**，側板口袋底的單向楔扣住 |
| 左／右側板 主板段 | 主板段外牆（**無下裙**）+ 四道內面滑槽（碟架那道**後端是盲端 182.04**）+ 底板 bead 凹槽 + **後牆單向楔 ×3 公件**；左側板另有 **PSU 長肩**（z 86.52–89.52）。**不開通風孔**。**外表面朝下印**（楔凸出的方向＝列印 Z） | 自 +Y 滑上底板 |
| 頂蓋 主板段 | **單片**，兩側下伸舌 + 後端半搭接 | **自 +Y 滑入側板槽**，後端鑽進鉤唇下 |
| 前罩_含進氣柵 | 前段外殼（A1 床 256 逼出來的分件）+ 碟托盤穿過的口 + 下段進氣柵 + 電源按鈕孔 + **三段咬住側板整厚料的缺口** | **自 +Y 套上主板段外表面的減薄帶**（10 顆 detent） |
| 碟架_四層導軌 | 左右立板（厚 6.0）+ 頂板 + **兩側各兩條橫樑**；內面 4 層導軌槽 | **四片側舌插進側板 z 165.82–171.82 的槽，自 +Y 推到盲端 182.04 止住** |
| 碟托盤（**×4**） | 碟平躺鎖在上面（底面孔 ×4）+ 前擋板（＝前面板的一部分，含柵與指拉凹） | **自 +Y 插入碟架導軌** |
| PCIe 槽蓋 | 封空槽 | 舌入袋、頂端折耳被壓條壓住 |
| PCIe 壓條 | 四槽共用的可拆固定件，**長在機殼外面** | **往 +Y 壓上兩顆蘑菇柱，再往下落 3.5（keyhole）** |
| 主板壓帽 | 把主板壓在粗肩與壓帽之間（印 9 顆） | 旋在細軸的梯形外螺紋上 |

**對位榫（12 處）：第七輪整組刪除**——它是甲板托盤時代的東西。
**下裙與全部 M3 螺母座：第八輪整組刪除**——使用者要求全滑槽組裝。

**機殼螺絲：0 顆。** 保持力來自互鎖鏈 + detent：
頂蓋兩側舌上方仍是牆料（抬不起來）→ 後端鑽進後牆頂鉤唇（前後鎖住）
→ 側板連帶抽不上去 → 前罩擋住頂蓋往 +Y 滑出。

**第十一輪把這句話拿去量了**（`--- 保持力真相表（六向約束）---`）：
8 個機殼件 ×6 方向，48 個方向裡 **46 個 `play ≤ 0.75`**，只有前罩 +Y 與碟托盤 +Y
是**宣告過的**釋放方向。量之前有兩條是紅的：
**碟架往 −Y 浮 3.00 mm**（側板槽沒有盲端）、**後牆往 −Y 走 12 mm 完全沒有東西擋**
（八顆半球是唯一阻力，而半球受拉會 cam-out）。兩個都在 `failures=0` 底下 ——
干涉檢查問「有沒有重疊」、裝配掃描問「進得來嗎」，**沒有人問「出得去嗎」**。
現在：碟架槽改盲端（`RACK_STOP_Y`）、後牆六顆改**不對稱單向楔**（推得進、拉不出）。

> **為什麼是「底板插進牆」不是「牆插進底板」：** 主板躺下之後，內寬只比板寬多 4.04、
> 內深多 1.00，板底 6.35 又封死 z∈[2.4, 8.75] → **任何從底板往上長的定位唇，
> 右側和後側都會直接戳進主板**。這和第七輪「螺母座只能放地板以下」是同一條約束。

> **為什麼角落不用燕尾：** 燕尾大端要 6–8 mm，牆厚只有 2.4。改用薄定位舌 + detent，
> 而 detent 半徑受舌厚限制：**`2R ≤ 舌厚 + 凸出量`** → R = 0.9、凸出 0.6。

## 3. 主板托盤為什麼「怪」— 其實可能是對的

規範要求：

```
板底 ────────── 全域懸空 ≥6.35 mm
     ▲ 僅九個 10.16×10.16 keepout 內的 standoff 可碰板
```

故正確結構是：

- **外框 + 肋 + 九組 pad／粗肩**（抬高 6.35，粗肩之上再長細軸與螺紋，壓帽自板面鎖下）  
- **不是**整片貼板的鐵托盤  
- 中間挖空＝給板底元件與走線  

「看起來不像金屬 pan」≠ 違規。  
`PCIeBlank` 在總成裡停放於機殼外側＝**獨立零件座標**，避免與已裝卡的虛擬件重疊。

## 4. 驗證分層（誠實）

| 層級 | 本專案現況 | 意義 |
|------|------------|------|
| A. 參數／單元測試 | 有 | 常數與公式自洽 |
| B. CAD 幾何 verify | 有（void、孔距、干涉、A1、穿艙） | **不是**實機認證 |
| C. 規範條文對照 | 部分（本清單） | 介面尺寸 |
| D. 實機試裝／EMI／剛度 | **無** | 未做 |
| E. FDM 牙壽命／間隙校準 | **無** | 榫已刪；現在要校的是 `MB_NUT_GAP 0.20`、`PCIE_BAR_FIT 0.3`、`TOP_FIT_GAP 0.4` |
| F. 可印性（Solids／薄壁／床尺寸） | **有（2026-08-09 起）** | 每件 `Solids==1`、I/O 邊料 ≥3.34、A1 床邊 <6 mm 出 WARN |
| G. 規格值溯源 | **有（第三輪起）** | verify 逐顆比對 ATX 四孔、CEM 擋板、SFF-8301 碟側孔 |
| H. **裝配動作** | **有（第五輪起）** | 把包絡沿裝拆方向掃出來做布林：PCIe 抬升 4.50、碟垂直抽出 147、螺絲三段路 |
| I. **檢查本身非空** | **有（第五輪起）** | `_run_negtest.py` 把舊病灶塞回幾何，對應檢查必須變紅（**97/97**） |
| J. **目視複檢** | **有（第五輪末起）** | FreeCAD GUI 重開最新 FCStd，逐件看四視角（硬規則 18） |
| K. **料的必要性** | **有（第六輪起）** | 每塊料要說得出擋住／承住／定位什麼；減完補「舊東西不准回來」的檢查 |
| L. **規格淨空** | **有（第七輪起）** | 板底 6.35 + Area A/B/C 做成**實體**對全部印件布林，不是探幾個點 |
| M. **走線可行** | **有（第七輪起）** | 「電源出線口→主板上方」9 探點、**SATA 走線廊 12 探點**必須全空 |
| O2. **組裝順序可行** | **有（第十輪起）** | `ASSEMBLY_STEPS` 逐步掃描：第 i 件掃的時候場上只有第 0..i−1 件。第八～九輪只驗「在最終場景裡動得了嗎」，於是文件寫的順序（後牆先落下）**兩輪沒被驗過、而且做不到** |
| P2. **配合間隙 ≥ 下限** | **有（第十輪起）** | 每一道滑槽的四個面各一個探點，量出來必須是空的。第九輪以前全機 `distToShape` 都是 0.0000 |
| N. **刻意的規範偏離／取捨** | **有（第八輪起，第九輪 2 項）** | 偏離值由實測或幾何導出、規格 literal 另存並驗它沒被改、verify 發 `WARN`。目前只剩一項：`PCIE_CARD_LEN = 189.00 < 230`（Area A 的偏離第十輪已消除）。另有**第四類「規格沒寫、只好假設」**：`PSU_FAN_DOWN`（大面風扇朝向 ATX12V 沒有規定） |
| O. **配合面的下限** | **有（第九輪起）** | 「≤ 上限」的地方也要驗「≥ 下限」：零間隙布林量不到（`common()` = 0）、掃描也量不到。用 `distToShape()` 或把間隙寫進導出式 |
| P. **結構連續性** | **有（第九輪起）** | 細長件沿整根**逐點取樣**、兩個固定端都要驗。探點只回答「有沒有料」，不回答「另一端接到哪」 |
| Q. **保持力（掉不掉得出來）** | **有（第十一輪起）** | 每個機殼件 ×6 方向量 play：46 鎖住 + 2 個宣告過的釋放方向。前十輪的干涉檢查問「有沒有重疊」、掃描問「進得來嗎」，**沒有人問「出得去嗎」**——碟架浮 3.00、後牆 −Y 走 12 mm 沒東西擋，兩個都在 `failures=0` 底下 |

`failures=0`＝**B 層腳本通過**，不是「機殼設計認證通過」。

> 2026-08-09 教訓：舊 verify 沒有 `Solids==1`，於是「托盤裂成 13 塊散件」在 `failures=0` 下漏過。
> **檢查沒寫進 verify 的項目，等於沒有被驗證。**
>
> 第三輪教訓：驗 **pitch 138×74** 這種聚合量會放過「四顆有三顆錯位」。
> **規格是逐顆座標，就要逐顆比。**
>
> 第五輪教訓：B∼G 全部在問「最終位置對不對」，於是 PCIe 卡插不進去、
> AC 插頭插不上、硬碟八顆螺絲鎖進塑膠，三個缺陷同時在 231 條全綠底下活著。
> **「東西在那裡」和「走得到那裡」是兩層。** 而且檢查若跟著參數一起錯就永遠是綠的——
> 所以規格數字對 literal 比、並且用負向測試證明檢查抓得到舊病灶。
>
>
> 第七輪教訓：使用者看一眼就說「**這樣根本無法走線**」。查下去發現那片甲板本身
> 就是「電源在板下」的產物，而它又生出六個穿艙孔、兩道走線廊、一整片托盤——
> **刪掉前提，那些全部一起消失**。同一輪還發現**九孔有七顆座標是錯的**：
> 圖上的標註只告訴你數值，不告訴你它在量哪兩點。有向量圖元就別讀標註。
>
> 第八輪教訓：**一個零件的「便宜」可能建立在另一個零件撐出來的空間上。**
> 第七輪的直立碟艙只吃 65.10 深，靠的是「電源把機殼撐到 192 之後本來就空著的高度」；
> 電源一往下挪（Area A 88.90→50），碟頂 171.4 反而比新的內頂 153.32 還高——
> **最省的零件變成了新的瓶頸**。同一輪還學到：刪掉一個「為約束而生」的特徵時
> （下裙 ← 螺母座），底層那條約束不會跟著消失，只會換個形式繼續咬人。
>
> 第六輪教訓：全綠、裝得起來，但**沒有一條檢查在問「這塊料在做什麼」**。
> 於是前檻與碟艙後壁背靠背當了六輪的兩片牆、走線廊肋高了 63 mm、四顆碟底下各壓著
> 一片實心方板——110 cm³（7.8%）的料沒有任何人要為它辯護。
> 同一輪還發現 PCIe **根本沒有螺絲固定**：防上抬掛在頂蓋上，
> 檢查只問「抬升被擋住了嗎」，沒問「擋住它的是不是固定件」。

## 5. 仍開放的風險（研究標出）

- **印製螺紋（主板柱＋壓帽）的保持力與反覆拆裝壽命**：真旋合徑向量 0.40、旋合 2.5 圈、
  芯徑 Ø2.30，扭力上限是「手緊」。CAD 只證明幾何咬得合、印得出來  
- **滑槽配合（0.30/邊）與 detent 保持力**：第八輪把全部機殼五金換成滑槽，
  第九輪加上前罩四面搭接與 PCIe keyhole，**第十輪才真的把 0.30 補到每一個配合面**
  （第九輪以前 `distToShape` 全機都是 0.0000）並加上底板 bead ×4、前罩 detent 共 10 顆。
  **第十一輪把後牆那六顆從半球換成單向楔**（半球受拉會 cam-out，而後牆是受 −Y 力
  最多的那一面）。幾何上鎖住 ≠ 力量夠：**插入力、保持力、直角面拆裝幾次會不會被
  磨圓，全部沒有測過**。鬆了會晃、緊了裝不進去，只有印一套才知道  
- **碟架的懸掛強度**：兩側各一條 1.2 深的舌，承 4 顆碟 ≈ 3 kg  
- **電源掛在後牆上的長期潛變**：20 N、CoM 距牆 ~70 mm，由左側板長肩 + 後牆凸緣承擔，
  四顆 #6-32 抗傾覆。PETG 常溫潛變沒算過  
- **熱**：全機只有電源風扇一顆，前柵面積算過（15939 > 11310）但**風壓與溫升沒量過**。
  而且**碟平躺堆疊比直立並排更難散熱**（層間只有 1.5 的氣隙 + 3.0 的托盤）  
- I/O shield 彈片咬 FDM 壁  
- **A1 床邊只剩 3.3 mm**（`CASE_W=252.68`，由 I/O keepout 逼出）：關 brim、床要平
- **不得宣稱「完全相容 microATX」**：Area A 已達 required **76.20**（第十輪起），
  但仍 < recommended 88.90（要達到得再 +12.70 mm 機殼高度）。
  使用者實測的散熱器 <50／記憶體 <40 現在只是**下限**，不再是決定值
- **PSU 大面風扇的朝向是假設，不是規格**（第十輪新增的第四類）：
  ATX12V v1.1 Fig.4 p23 的風扇開在**後面板**（80 mm），大面 120/140 風扇在哪一面
  這份規格沒有寫。`PSU_FAN_DOWN = True` 依使用者指定，verify 發 `WARN`；
  翻回來只要一個布林。**不得寫成「規格規定風扇朝下」**
- PCIe 折耳向內伸長**已解**（Fig.6-4 俯視 11.43，第四輪判讀）→ `PCIE_EAR_CLEAR = 12.43`；
  仍未解的是 21.59 凸緣在 20.32 槽距下如何互讓（CEM 無明文）
- `PCIE_LIFT = 6.0` 裡的 1.5 mm 操作餘裕沒有規格背書（4.50 有）——裝一次真卡才知道
- 前面板只有電源鍵，沒有 USB／音源／reset（取捨，不是缺陷）

- 托盤插卡時剛度（規範無剛度數值）  
- 接地／EMI（機械 PDF 不管，專案定案靠 PSU 24-pin）
