# microATX 九孔座標（microATX 1.2 **Figure 7 p18** 向量座標）

## 座標系
- **Datum：hole B = (0, 0)**
- **case +X = −intel +X**（平放可裝真板：從後方看 I/O 在左、PCIe 在右）
- **+Y**：朝前緣（遠離後 I/O）→ 硬碟艙
- 孔徑：Ø **0.156 in（3.96 mm）**

## ★ 第七輪整組修正（舊表七顆是錯的）

舊表寫「後緣 → 第一列孔（B/C/F）：0.900 in」，然後把 Fig.3 的 6.100 / 8.950
各減 0.900 當成「相對 B」。**`.900 [22.86]` 不是後緣→B 列，是 B 列 → F 那一顆。**

用 `fitz` 抓 **Fig.7 p18** 的向量座標（九個孔圓 + 板框同一比例尺 1.0044 pdf/mm）
就沒有解讀空間了，而且與 Fig.3 p12 的四個標註完全對上：

```text
.400 [10.16]  板後緣 → B 列          6.100 [154.94]  B 列 → R/S/H/J 列
.900 [22.86]  B 列   → F            8.950 [227.33]  B 列 → L/M 列
```

後果不是「差一點」：真板前緣其實在 **y = 233.68**（舊值 220.98），
第六輪的碟艙口在 221.48 → **主板會撞碟艙 12.7 mm**，而且九根柱有七根對不上孔。

## 板上元件高度分區（§2.4.1 Table 6 + Fig.7）

機殼的料只能在下表的 z 以上（板面 = `BOARD_TOP_Z` = 10.32）。
本專案把電源放到主板正上方，靠的就是這張表。

| 區 | case 範圍 | 元件高 | **機殼淨空** | 本專案取值 |
|---|---|---|---|---|
| A | x∈[−209.55,−52.07]，y ≤ 154.94（x≤−95.25）／180.34（x∈[−95.25,−52.07]） | 71.12 | 76.20 required / **88.90 recommended** | **76.20 = required**（電源底面 = 板面 + 76.20 + 肩 3 = 89.52；第十輪回到規範內） |
| B | x∈[−52.07, 34.29] 全深 | **15.24** | ≥ 元件高 | 卡自己佔滿，機殼只在 25.56 以上放料 |
| C | A 之外的左前區 | **38.10** | ≥ 元件高 | 碟艙搭接片自 48.42 以上（實取 130.37，讓開卡） |

板底：**≥0.250 in (6.35)**（§2.4.2）；只有九孔的 **0.400 in (10.16) 方形**內
允許機殼柱碰板 —— 印製粗肩 Ø8 與壓帽 Ø9.6 就是靠這條合法。

## 主板固定（第六輪定案，第七輪只換了柱長在哪裡）

| 段 | 尺寸 | 說明 |
|---|---|---|
| 粗肩 | Ø8.0 × 6.35 | 直接長在**底板**上（第六輪是長在甲板上）。6.35 = §2.4.2 板底淨空 |
| 細軸 | Ø3.50（芯 Ø2.30） | 穿主板孔 Ø3.96，單邊 0.23 滑配 |
| 外螺紋 | 梯形，牙距 2.0、牙深 0.60 | 真旋合 = 0.60 − 0.20（螺帽間隙）= **0.40** |
| 印製壓帽 | Ø9.6 × 5.0，12 道指握溝 | < 10.16 keepout；旋合 2.5 圈；**扭力上限＝手緊** |

> 舊版「印製細牙柱 + Ø12 旋蓋」在第四輪整組刪除：疊圓盤「螺牙」徑向凸出僅 0.40
> （低於 0.5 最小可印特徵），而且是**軸對稱環不是螺旋**，轉不進去；Ø12 又破 keepout。
> 現在 verify 用「相位轉 180° 必須撞」證明牙是真的螺旋（軸對稱的怎麼轉都不會撞）。
