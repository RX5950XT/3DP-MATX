# 零件清單與組裝說明（第十一輪）

## 外形

**單一長方體**：**252.7 × 301.0 × 180.1 mm**（寬×深×高），實佔 **13.70 L**。
第七輪 16.20 L → **−15.6%**。第八輪 13.22 L；第九輪 +6.0 mm 全部是層間氣隙。
**第十輪體積與高度一點都沒有變**（電源上移是往內部要空間，不是往外要）。
沒有階梯、沒有外凸的腳、**沒有下裙**——機殼整片底板落地。

> 靠牆擺時要留 **309.0 mm**：後牆外側最凸的是 PCIe 壓條的 keyhole 蘑菇柱
> （頸 5.5 + 頭 2.5 = 8.0），不是壓條本身（5.0）。第九輪的文件寫 306.0，
> 那是拿「壓條厚度」當外凸量算的，少報 3 mm。

高度是這樣疊出來的（每一段都指得到來源）：

```text

       ＋ 4 ×（托盤 3.0 ＋ 碟 26.1 ＋ 氣隙 1.5）           → 碟頂 173.82
       ＋ 碟架頂板 3.0 ＋ 滑配 0.30                        → 碟決定的內頂 177.12  ← 兩條同高
內頂 177.12 ＋ 頂蓋 3                                     → 180.12
```

## 保持力：裝好之後**掉不掉得出來**

`--- 保持力真相表（六向約束）---`（第十一輪新增）把每個機殼件往六個方向推，
量它撞到別人之前能自由走多遠。48 個方向裡 **46 個 play ≤ 0.75**（＝被鎖住），
只有兩個是**宣告過的釋放方向**：

| 件 | 可以走的方向 | 靠什麼留住 |
|---|---|---|
| 前罩 | +Y（唯一徒手可拆的蓋） | 10 顆半球 detent（刻意可 cam-out） |
| 碟托盤 ×4 | +Y（熱插拔） | 導軌摩擦 + 前面板 |
| 其餘 6 件 | **一個都沒有** | 榫在槽裡／盲端止擋／單向楔 |

第十輪這張表是紅的兩條：碟架往 −Y 浮 **3.00 mm**、後牆往 −Y 走 **12 mm 都沒東西擋**。
兩個都在 `failures=0` 底下 —— 干涉檢查問的是「有沒有重疊」、裝配掃描問的是
「進得來嗎」，**沒有人問「出得去嗎」**。

## 滑槽互鎖

**唯一來源是 `參數.ASSEMBLY_STEPS`；verify 照這張表逐步掃描**
（第 i 件掃的時候場上只有第 0..i−1 件）。第八～九輪文件寫的順序是
「後牆先落下、側板後落下」——那個順序**其實做不到**：側板一旦在位，
定位舌口袋的上方是實牆，後牆根本落不進去（negtest #35 實測會撞）。

```text
① 底板 ─放在桌上（基準）
② 左右側板 ─自 +Y 往 −Y **滑上底板**（內面 z∈[1.10, 2.70] 的槽咬住底板兩側 1.0 厚的
   上半舌；槽的**下方保留 1.10 整厚牆料**當承載唇、背後保留 0.80）
   └ 滑到最後 30 mm，底板側緣的**縱向 bead**（R 0.9／凸 0.6）落進側板的凹槽 → 卡住
③ 後牆 ─自 −Y 往 +Y **推進去**：兩端的定位舌插進側板後端口袋，×3／側的
   **不對稱單向楔**（楔長在側板口袋底、舌上自根部往前開缺口）——
   斜坡 1.5 讓舌爬上去，到底時直角面 0.6×5.0 卡在缺口前緣 → **拉不出來**；
   同時底板後緣的舌插進後牆低位槽（半球 ×2，這兩顆刻意保持可 cam-out）
④ 電源／主板／PCIe 卡（此時上方全開）
⑤ 碟架 ─自 +Y 滑入側板內面 z∈[165.82, 171.82] 的槽（四條橫樑各伸一片舌），
   **推到 y=182.04 的盲端止住**（第十輪槽開到 179.34，碟架往後浮 3.00 mm）
⑥ 頂蓋 ─自 +Y 滑入側板 z∈[174.12, 177.42] 的槽，**咬合 1.30**（第九輪只有 0.40）
   └ 頂蓋底面與碟架頂板之間留 0.30（第九輪共面，滑入時要磨過 100 mm）
   └ 槽**上方仍有 2.70 牆料** → 抬不起來；滑到底後端鑽進後牆頂鉤唇下方
⑦ 前罩 ─自 +Y 套上：四面半搭接 + **10 顆 detent**（左右各 3、頂底各 2）
   └ 再加**三段整厚料咬進搭接殼的缺口**（見下）→ Z 向被扣死，不只靠摩擦
⑧ 碟托盤 ×4 ─自 +Y 插入碟架導軌
（PCIe 壓條不在這條鏈上：往 +Y 壓上後牆外的兩顆蘑菇柱，再**往下落 3.5 mm**）
```

**一道滑槽的四個數字**（牆厚 2.4 全部要塞進去）：
舌伸出 **1.30** → 槽深 = 舌 + 滑配 **1.60** → 槽背後剩 **0.80**（＝最小可印壁厚）；
底板舌厚 1.00、承載唇 **1.10**。
**第十輪之前只有「舌伸出」是對的**：量出來 `distToShape(底板, 側板/後牆/頂蓋)`
**全部 0.0000** —— 底板本體寬度剛好等於內腔 247.88、舌尖與槽底共面、舌底與唇共面。
零間隙不是精密，是裝不上。

**前罩的第三個咬合**：側板的搭接減薄帶在**三道內面滑槽的正後方不減薄**
（1.6 槽 + 1.5 減薄 = 3.1 > 牆厚 2.4，那三段本來是**被切穿的**），
前罩的搭接殼挖對應缺口 → 整厚料是榫、缺口是槽。這是修一個缺陷順手變出來的。

**半球是摩擦力，不是保持力**（第十一輪）：受拉時球會沿球面自己爬出來（cam-out）。
要「拉不出來」就得有一個**法線平行拉出方向的直角面**。純滑動接合的公母
**進出走同一道邊**，所以不對稱只能做在**公件**上（斜坡朝來的方向、直角面朝走的
方向），母件只是個缺口 —— 而且缺口要**自舌根往前開**，不是在舌中間挖孔：
直角面推的是缺口前緣，那道邊後面必須是整片舌料；開在中間的話前緣只剩 0.45 mm，
一拉就掰斷。**哪些單向、哪些留可 cam-out 是設計決定**：拆機路徑上的最後一道
（前罩）留半球，全部做成單向就永遠拆不下來。

> **側板必須「外表面朝下」印。** 楔凸出的方向就是側板的厚度方向＝列印 Z；
> 內面朝上時斜坡是往上爬的斜面（21.8°，不需支撐）、直角面是一道垂直牆，都好印。
> 反過來把內面朝下，那三個楔全變成 0.6 mm 的懸空斜面。

**為什麼角落不用燕尾**：燕尾大端要 6–8 mm，而牆厚只有 2.4——兩片 2.4 的板在角落
咬不住任何燕尾。改用「薄定位舌（1.2）＋ detent」。
**detent 的公母要放在有料的那一邊**（第十輪）：球長在 2.4 的牆上、坑挖在 1.2 的舌上。
反過來（第九輪的做法）算下去是「槽深 1.5 + 凸出 0.6 + 坑加大 0.15 = 2.25，牆只剩 0.15」。
**行程長的接合（側板 264 mm）不能用球**：球會一路磨 → 改成「球長在**不動**的
那件、靠近它的後端」，槽自後端掃過來，只有最後一段過盈。

**為什麼是「底板插進牆」而不是「牆插進底板」**：主板佔滿內腔（左 3.54／右 0.50／
後 1.00），板底 6.35 淨空又封死 z∈[2.4, 8.75]——任何從底板往上長的定位唇，
右側和後側都會直接戳進主板。這和第七輪「螺母座只能放地板以下」是同一條約束。

## 硬碟：平躺 4 層，疊在主板前段的正上方

```text
姿態：147 沿 X、101.6 沿 Y、26.1 沿 Z，**接頭端朝 +X**（使用者指定朝內／朝 PCIe 側）
位置：x ∈ [−177.65, −30.65]   y ∈ [182.34, 283.94]   z 從 51.42 起，每層 **30.60**
碟架：x ∈ [−183.65, 5.35]（寬 189.00，**置中**，左右內牆各餘 29.44）
```

- **後緣 180.34 是硬界線**：碟的 x 帶跨過 `AREA_A_STEP_X`(−95.25)，
  那一段 Area A 一路延到 **180.34**（Fig.7 p18）。再往後就是散熱器空間。
- **碟架底面 48.42 = Area C 淨空頂**；最底層托盤底 51.42，中間那 3.0 是
  **最底層導軌槽的承載料**——第八輪沒有它，最下面那層的托盤舌底下是空的。
- **接頭走線區（第九輪的重點）**：碟的 +X 端面 → 右立板內面留 **30.00 mm**。
  第八輪右立板整片貼著 101.6 × 26.1 的接頭端面（四層各 15.8–18.0 cm³ 的實心料），
  **SATA 與電源接頭根本插不上**。托盤一路鋪到右立板，當接頭區的底。
- **層間氣隙 1.5**：第八輪的節距讓碟頂正好貼死上一層托盤底（布林量不到，
  面接觸 `common()` = 0；掃描也量不到，同一個平面滑過去）。
- 碟架**兩側各兩條橫樑**（y = 188.34 / 226.18），同側兩條之間刻意留空讓線穿過。
- SATA 接頭沿端面的確切位置在 SFF-8323，`參考/` 沒有那份規格 → **整個端面全讓開**，
  不猜位置。

**換碟不必拆任何東西**：托盤自前面板直接抽出（行程 101.6）。托盤的前擋板**就是**
機殼前面板的一部分，上面有指拉凹與兩排進氣柵。

## 走線

**電源與主板在同一個腔，中間沒有任何板子。**

```text
電源出線口（前緣 y=129.34）→ 直落 66 mm → 主板上方（24-pin / EPS）
電源前緣 149.34 → 碟架後緣 180.34：留 31 mm 走線帶
SATA：碟的 +X 端 → 碟架內的接頭區（30 寬）→ 碟架右側空帶（29.44）→ 往下到板右緣
```

建議 PSU：**非模組**、深度 ≤140 mm（艙深預留 160，但 >160 會越出 Area A 的 154.94 界線）。

## 氣流

```text
前柵（前罩下段 3 排 + 每片碟托盤擋板 2 排，合計 15939 mm²）
   → 碟（層間 1.5 氣隙）→ 主板腔（CPU 散熱器）→ 電源風扇（朝下吸）→ 電源後面板排出
```

**側板、頂蓋、底板都不開孔**：氣流只有這一條，多開的孔只會讓它短路。
> 面積算過（15939 > 120 風扇迎風 11310），**風壓與溫升沒有量過**。
> 層間 1.5 mm 是**裝配間隙**，不是散熱設計。

## PCIe

**四槽全高，一個都沒少。** 換來的代價是**卡長上限 189.00 mm**（由碟架後緣導出）——
碟架置中之後卡與碟架的 X 帶重疊，兩者只能二選一。189.00 仍 > CEM 半長卡 167.65，
使用者指定只插網卡類的卡。低卡 DIM A = 72.30 見 CEM Fig.6-17 p110，備而不用。

**壓條長在機殼外面**（使用者要求）：後牆外表面凸出**兩顆蘑菇柱**（＝那個「凸出來的
結構」），壓條往 +Y 壓上去讓柱頭穿過寬口，再**往下落 3.5 mm**，柱頭就被窄槽兩側
各 2.2 mm 的料扣住（keyhole）。內側四個舌各自穿過自己那個開孔的抬升讓位帶，
壓在擋板頂緣上方 0.4。舌只伸入 2.0（仍在 2.4 的牆體內）——**機殼內部一點料都沒有**。

> **第八輪的橫縫已經刪掉。** 那時壓條是沿 X 滑進 T 軌的，四個壓舌要走完全程，
> 於是抬升帶被打成一條通到機殼右緣的連續橫縫——**三根 1.42 mm 的肋因此
> 從兩端固定變成 112.75 mm 的懸臂**（斷面 1.42×2.40，k ≈ 0.006 N/mm）。
> 使用者一眼看出「幾乎完全懸空、印得出來嗎」。
> 現在：橫縫刪除、開孔上方是 6.0 mm 的連續繫樑、肋再往**機殼外**加厚 4.0
> （斷面 1.42×6.40，抗彎慣性矩 1.64 → 31.0 mm⁴，×19）。

**換卡：** 壓條抬 3.5 mm → 往 −Y 拔下 → 卡垂直往上拔（指入深度 4.50，CEM Fig.6-17）。
不必拆頂蓋、不必拆側板、不必沿 X 滑。

## 組裝順序

> **這一節第十輪整個改過**（使用者指定的順序，也是唯一做得到的順序）。
> 舊版寫「後牆先立起 → 側板落下 → 底板滑入」——那三步的第二步就做不到了。

1. **底板**平放在桌上。這是基準件，之後都以它為準。
2. **左右側板**自機殼前方（+Y）往後（−Y）**滑上底板**：把側板的低位槽對準底板
   側緣的舌，一路推到底板後緣齊平。最後 30 mm 會感覺到 bead 的阻力，推過去就卡住。
3. **後牆**自機殼後方（−Y）往前（+Y）推進去：兩端的定位舌進側板後端的口袋。
   舌的前緣會爬上口袋底的斜坡（每側 3 個），推到底時**「喀」一聲**落進缺口 ——
   那三個是**單向楔**，直角面朝後，**推得進去、拉不出來**。
   底板後緣的舌同時進後牆的低位槽（2 顆半球，這兩顆是可以拉出來的）。
4. **PCIe 卡**（此時上方全開）：舌尖對進後牆內面的舌袋，卡垂直往下壓進插槽。
   空槽以 `PCIe槽蓋` 同法裝入。
5. **主板**：抬到細軸頂之上（板底 ≥16.3），往 −Y 推進 I/O shield（I/O shield 先自
   後牆外側壓入），再落到九根 Ø8 粗肩上 → **旋上 9 顆印製壓帽（手緊即可）**。
6. **電源**：自上方落入。**先往 +Y 移 7 mm** 讓開後牆頂鉤唇，落到「後牆凸緣 +
   左側板長肩」上（z = 89.52），再往 −Y 推到位，鎖 4 顆 #6-32。
   **風扇朝下（朝主機板）**；機殼上的四孔是 ATX12V Fig.4 那組非對稱孔
   **繞深度軸轉 180°** 之後的位置：`(6,6) (144,6) (144,70) (30,80)`，
   自 PSU 後面板左下角量、從機殼後方看。
   ⚠️ 風扇在哪一面 ATX12V 沒有規定，這是依使用者指定的假設；
   若你的電源風扇朝向相反，改 `PSU_FAN_DOWN = False` 重跑 build。
   **PSU 的後面板是外露的**：AC 插座、電源開關、排風柵都直接看得到、按得到、插得進去。
7. **接線**：電源出線口就在主板正上方，24-pin／EPS 直接接。
8. **碟架**自 +Y 滑入左右側板的槽，推到**槽的盲端（y=182.04）碰底為止** ——
   碰到就是到位了，不要再用力。第十輪這道槽是通到 179.34 的，碟架會往後多跑 3 mm。
9. **頂蓋**自 +Y 往 −Y 水平滑入，推到後端鑽進後牆頂鉤唇下方。
10. **前罩**自 +Y 套上主板段前緣（地板舌壓在底板前緣的減薄帶上，
    L／M 兩根主板柱從前罩地板的讓位槽穿過；三段整厚料滑進搭接殼的缺口，
    推到底時 10 顆 detent 一起卡進去）。
11. **硬碟 ×4**：每顆先用 4 顆 #6-32×1/4" 自托盤底面鎖進碟的**底孔**
    （三排孔挑碟上有的兩排：離接頭端 41.28 / 85.73 / 117.48），
    **接頭端朝 +X**，再把托盤自前面板插入到底。
12. **前面板按鈕**：10 mm 按鈕自前罩下段外側穿入、內側鎖螺帽（碟架右側空帶，
    x≈20.1），線沿該帶到主板 PWR_SW。
13. **PCIe 壓條**往 +Y 壓上兩顆蘑菇柱，再往下落 3.5 mm，翼上的 detent 卡住。

**拆卸**：反序。
- **換硬碟：直接從前面抽托盤**，什麼都不用拆。
- **換 PCIe 卡：壓條抬 3.5 mm 拔下 → 卡往上拔**，頂蓋不用動。
- **拆電源：** 退 4 顆 #6-32 → 往 +Y 移 7 mm → 往上取出（需先滑開頂蓋）。
- **拆後牆：不要硬拉**，那六個楔是單向的，拉只會把舌掰斷。
  順序是：前罩往 +Y 扳下來 → 頂蓋往 +Y 抽出 → 左右側板往 +Y 滑走
  （楔長在側板上，側板一走楔就跟著離開）→ 後牆這時只剩底板那兩顆半球扣著，
  往 −Y 一拉就下來。

## 重建

```text
FreeCADCmd -c <root>\scripts\_run_build.py     # 建模 + 匯出 STL/FCStd
FreeCADCmd -c <root>\scripts\_run_verify.py    # 幾何 + 規格淨空 + 虛擬件 + 裝配動作
FreeCADCmd -c <root>\scripts\_run_negtest.py   # 負向測試：新檢查抓得到舊病灶
python 腳本\渲染預覽.py                          # 無 GUI 總成視圖 → 規格/總成視圖_*.png
python -m unittest 測試/test_參數.py -v                 # 56 tests
```

路徑一律走 ASCII 的 `scripts` junction：FreeCADCmd 吃不下中文 argv。
`FreeCADCmd` 不在 PATH 時先補：`$env:PATH = "C:\Program Files\FreeCAD 1.2\bin;$env:PATH"`
GUI 開著時 build 改磁碟檔，GUI 不會自動更新——量到舊尺寸先 close→open 重讀。
